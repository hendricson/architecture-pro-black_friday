## Задание 6. CDN

### Новые компоненты

| Сервис | Описание |
|--------|-----|
| CDN | Кэширующий прокси-сервер, балансирует нагрузку между API инстансами |
| pymongo инстансы 1,..., N | Горизонтально масштабируемые инстансы приложения |

### Принцип работы

* Входящий трафик -> CDN -> распределяется по доступным API инстансам
* CDN кэширует ответы от API инстансов
* При добавлении/удалении инстанса Consul автоматически обновляет реестр
* CDN узнаёт об изменениях и корректирует балансировку
