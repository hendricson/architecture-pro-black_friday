## Задание 5. Service Discovery и балансировка с API Gateway

### Новые компоненты

| Сервис | Описание |
|--------|-----|
| API Gateway | Точка входа для всего трафика, балансирует нагрузку между API инстансами |
| Consul (Service Discovery) | 	Автоматическая регистрация/дерегистрация API инстансов |
| pymongo инстансы 1,..., N | Горизонтально масштабируемые инстансы приложения |

### Принцип работы

* API инстансы при запуске регистрируются в Consul
* API Gateway получает список доступных инстансов из Consul
* Входящий трафик -> API Gateway -> распределяется по доступным API инстансам
* При добавлении/удалении инстанса Consul автоматически обновляет реестр
* API Gateway узнаёт об изменениях и корректирует балансировку
